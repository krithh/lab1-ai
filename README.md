# Лабораторная работа №1

## Предварительная обработка данных с использованием pandas

В работе используется датасет Titanic с платформы Kaggle.

## Выполненные действия

- загрузка датасета через pandas;
- просмотр структуры и основных характеристик данных;
- подсчёт пропущенных значений;
- заполнение пропусков медианой и модой;
- нормализация числовых признаков с помощью MinMaxScaler;
- преобразование категориальных признаков методом one-hot encoding;
- удаление сложных текстовых признаков;
- сохранение обработанного датасета в CSV.

```text
lab1-ai/

```

## Запуск проекта

Установить зависимости:

```bash
python -m pip install -r requirements.txt
```

Открыть `lab1.ipynb` в Jupyter Notebook или Visual Studio Code и выполнить все ячейки по порядку.

## Результат

Получен обработанный датасет, не содержащий пропущенных и текстовых значений. Числовые признаки приведены к единому масштабу.
